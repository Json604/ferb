# FERB.app (`ui/`): for agents

Everything about the app lives in `kb/`: its decisions (area `app`, `APP-*`), the rules for agents working on the UI,
open work and live checks. Before editing a file here, run `tools/kb/run kb show <file>`; for the whole area,
`tools/kb/run kb area app`. The repository's working agreement is the root `AGENTS.md`. To work on the first-run intro
without a real FERB behind it, see `ui/mac/FERBNotch/PLAYGROUND.md`.
