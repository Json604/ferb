## Architecture
Keep the current gateway, P19 ledger, worker verification and resource cleanup. Add typed dependency plans and a durable SQLite step store. Each executable plan step has its own worker; independent ready steps run concurrently, results and coverage notes survive restart. A resumed interrupted step receives its earlier evidence and unresolved action ledger and cannot replay an unknown action without P19 approval. Time/event waits persist their wake condition; event data is never owner authority.

The existing Supervisor.send planning phase is serialized per conversation only until a plan is registered, so subsequent messages can route while its execution continues. The TTY prompt consumes streams in background threads, queues questions and enters hidden input only after an explicit empty Enter. Owner attachment uses a code-owned process-input lease, blocking worker input during takeover.
