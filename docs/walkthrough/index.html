    Read HLD and LLD without jargon

    HLD (high-level design) is a map of responsibilities and connections. A box is not necessarily a separate process. Here, most green/code responsibilities live inside one Python daemon. Workers and coding workloads have separate process lifetimes.

    LLD (low-level design) is a sequence: columns are participants, time runs downward, arrows show a call or returned observation. This guided view expands the selected example; the Mermaid source retains all conditional branches.

    Model decision means an agent interprets intent or evidence. Code mechanism means validation, transport, ownership or lifecycle. A platform observation may still be incomplete. A trace observation is evidence from a specific historical run.
