# 0.22 test contract migration

The owner replaced the 0.18–0.21 action-policy contract on 2026-10-03. The following tests asserted behavior explicitly removed: mandatory action approvals, undo holds, label/phrase/identity/exposure gates, and automatic loop/reconciliation routing. They are retired, not skipped. Git history preserves them.

Replacement contracts live in `tests/test_orchestrated_control.py`, refreshed gateway/browser/files/setup tests, and the existing cancellation, ownership, secret, background-driver and truthful-verification tests. Scripted decisions prove routing and execution, not real model judgment. Owner acceptance is still required.
