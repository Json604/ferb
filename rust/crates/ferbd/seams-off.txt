# The seams ferbd deliberately leaves off, each with why (read by tests/seams_wired.rs).
#
#   off <id> | <why>                      an `off("id", value)` in the composition
#   default <Trait>::<method> | <why>     a trait default the named implementation keeps
#   value <field> | <why>                 a struct field set to `None` that is plain data, never a seam
#   trait <trait file> <Trait> <impl file> <Type>   a trait whose defaults are checked
#
# Paths are relative to rust/crates/. A reason cites the Python line that is also empty there, or says what makes
# the seam unneeded in this program.

# --- deliberately off ---
off chat.click_through | ChatDeps' `ui.click_through` handler is replaced by group C's (compose/mod.rs registers areas_c after the chat RPCs; Python chat.py:146 is the same one handler), which reads the Mac driver's report.
off chat.conversations | ChatDeps.conversations is no longer read: chat.status and conversations.list read the supervisor's own conversation store, as Python's chat.py:118 reads `supervisor.conversations`.
off keychain.refused | A daemon started with `Keychain::Refused` (the test stand-ins) never reaches the Keychain or the signed helper (TEST-508); the real daemon uses the signed helper.
off keychain.refused_security | As keychain.refused: `/usr/bin/security` is never run by a daemon started for a test.
off jev.key | Jev is paid and switched off (owner 2026-10-27: notices paused until a Jev-free decision engine); its key is never read, as Python's areas/jev.py:24-48 with `[jev] on` unset.
off events.attention_arrived | compose.py:231 hands `perception.attention` to Jev; with Jev off nothing publishes it.
off tree.read_clock | about's `tree_of` only reads the task tree; a read never asks the tree's clock.
off notices.read_clock | `attention_notices.unseen()` only reads; its clock is never asked.
off call.caller_left | An in-process gateway call (a probe read, a check's tool, the model tool bridge's own call) has no RPC caller that could leave; only `tools.call` over the socket carries one.
off runtime.retried | Codex and Claude retry inside their own programs; only the API loop reports its retries (runtimes/api.py:148-149, 237).
off browser.ask_without_context | The driver asks for a login code or a secret without a tool context only when no context exists; every gateway call carries one, so `ask_code_for`/`ask_secret_for` are the paths used.
off browser.peer_elsewhere | Off macOS nothing can tell which app started a native host, so every connection is refused (fails closed); FERB.app runs only on macOS (PROJ-506).
off browser.data_dirs | `browser_data_dirs` replaces discovery only in Python's tests (main.py:182 passes None in the real daemon).
off browser.no_wake_page | The wake page couldn't bind 127.0.0.1 (logged at start): no wake address exists; Python's WakeServer always starts, so this happens only on a broken host.
off desktop.app_window | The gateway's first look at a Mac app runs through the call hooks' AppWindows (tools/mac.rs), the one path; nothing in this program calls the desktop area's `app_window`.
off front.client | The supervisor's front-window seam carries no sending client's pid; FERB.app is the only client and FERB's own processes are never the front window (`own`), so the window it would skip is never chosen.
off applescript.sandbox_rest | desktop.py:317 gives AppleScript's sandbox only the apps and the events' socket; the rest of the shell's options stay at their defaults.
off input.no_tap | Without the Mac's parts there is no owner-input tap, so foreground input is never available (a test daemon); the real daemon reads the tap.
off hearing.no_capture | Without the Mac's parts no app's sound can be captured (a test daemon); the real daemon captures through ScreenCaptureKit.
off hooks.shadow | The gateway's shadow advice is Jev's; Jev is off (owner 2026-10-27), as Python's HookParts gets no shadow then.
off reader.clock | A read-only store (conversation.read, task.evidence) never asks its clock: nothing is written.
off reader.ids | task.evidence only reads the evidence store: no id is ever made.
off reader.publish | A read-only store or trail (conversation.read, trail.query) never publishes: nothing is written.
off reader.device | trail.query only reads: the device id is needed only to record.
off reader.paused | trail.query only reads: the pause gates recording only.
off reader.test_task | trail.query only reads: test runs are told apart only when recording.
off reader.paint | task.evidence only reads stored pictures: nothing is painted.
off records.conversation_publish | conversations.py:161 publishes only from `observe`; this store applies the owner's changes, which publish nothing.
